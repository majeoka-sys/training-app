GitHub Pages公開手順

GitHub Pages公開用ファイル：
01_GitHub公開用/index.html

公開先リポジトリ：
https://github.com/majeoka-sys/training-app

公開URL：
https://majeoka-sys.github.io/training-app/

更新手順：
1. 00_最新本番/training.html を修正
2. 動作確認
3. 01_GitHub公開用/index.html に同じ内容を反映
4. GitHubリポジトリへ index.html をアップロードまたはコミット
5. GitHub Pages の反映を待つ
6. ブラウザで確認

キャッシュ対策：
公開後すぐに反映されない場合は、URL末尾にバージョンを付けて確認する。

例：
https://majeoka-sys.github.io/training-app/?v=39

または、
https://majeoka-sys.github.io/training-app/index.html?v=39

注意：
- training.html ではなく index.html をGitHub Pages用に使う
- GitHub Pagesはアプリ本体HTMLを配信するだけ
- 記録データは各端末のlocalStorageに保存される
- スマホとiPad miniは自動同期ではない
- 端末間で使う場合は、バックアップ書き出しと結合インポートを使う
